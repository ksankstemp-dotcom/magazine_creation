# Local Umbrella Media // Print Publishing Studio

An interactive, pre-press print publishing studio and editorial layout design suite built for **Local Umbrella Media** and **Real Producers Magazine**.

---

## 🌟 Key Capabilities & Features

1. **Cover Masthead & Personalization Suite**:
   - Custom top offset spacing slider (`0–140px`) to align titles cleanly with subject photography.
   - Independent primary and secondary typography scaling and custom color palettes (Gold/White, Champagne/Bronze, Emerald/Gold, Custom).
   - Dynamic script tagline font engines (Playfair Italic, Caveat, Alex Brush, Pinyon Script, Great Vibes, Sacramento).

2. **Modular 16-Page Full Print Engine**:
   - **Interactive Spreads & Single-Page View**: Seamless switching between 2-Page spreads, all-sheet stacks, and single-page inspection.
   - **Pre-Press Certified**: 300+ DPI layout grids, CMYK color space safety margins, and 0.125" bleed zone overlays.
   - **Approved Page Assets Vault**: 1-click page certification and instant cross-issue reuse.
   - **Interactive Drag & Drop Page Reordering**: Effortlessly re-arrange publication spreads and issue page sequences.
   - **Minimalist Luxury Back Cover**: 3-tier luxury hierarchy with gold sponsor seal, open scenic photography, and floating frosted glass pedestal.

3. **Client Asset Intake & Media Vault**:
   - Multi-tenant client isolation for advertisers, cover profiles, and verified sponsors.
   - Reusable content library and high-resolution plate management.

4. **17 U.S.C. § 1202 Digital Proof Security**:
   - Optical Guilloche lattice, watermarking, and pre-press copyright preservation.

## 🚀 Getting Started

### Local Setup
Launch a local static web server from the project root:

```bash
# Using Python
python -m http.server 8080

# Or using Node.js / npx
npx http-server -p 8080
```

Open your browser to `http://localhost:8080/`.
